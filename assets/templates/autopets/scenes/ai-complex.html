AI를 잘 쓰려면 알아야 하는 것들

CONTEXT → PLAN → ROUTE → TOOLS → VERIFY

01CONTEXT COMPACTION

대화가 길어질수록 목표·제약·결정·남은 작업을 다음 실행에 필요한 상태로 압축한다. 요약에서 빠진 조건은 원문과 대조한다.

context_window → retained_state
constraints / decisions / open_tasks

02PLAN MODE

요구사항과 불확실한 조건을 확인하고 실행 계획을 합의한다. 계획을 써 달라는 지시와 실제 실행을 제한하는 모드는 구분한다.

clarify → plan → user_confirmation
execution_gate = awaiting_approval

03MODEL GUIDANCE · ROUTING

작업의 종류와 난이도, 속도·사용 부담을 고려해 모델을 선택한다. 계획용과 실행용 설정을 나누고 다음 실행의 적용값을 확인한다.

task_profile → model_selection
planned_setting ≟ effective_setting

04REASONING EFFORT

모델 종류와 추론 강도는 별도의 설정이다. 지원되는 조합 안에서 문제를 검토하는 강도를 정하고, 작업 결과로 적합성을 확인한다.

model ≠ reasoning_effort
light / medium / high

05SUBAGENTS

독립적으로 맡길 수 있는 작업을 분리한다. 각 작업의 범위와 필요한 맥락, 결과를 돌려받을 형식을 지정하고 상위 작업에서 합친다.

delegate(scoped_task, context)
collect → compare → integrate

06AGENT HARNESS

모델 호출 바깥에서 실행 단계, 도구, 상태와 권한을 관리한다. 작업의 시작·중단·재개·종료와 에이전트 사이의 관계를 연결한다.

runtime / state / tool_permissions
parent_task ↔ child_tasks

07SKILLS · MCP

스킬은 반복 활용할 절차와 지침을 묶는다. MCP는 외부 도구와 데이터에 연결하는 규약이며 연결 여부와 실제 사용은 구분한다.

skill = reusable_workflow
MCP = tools + resources + protocol

08AGENTS.md

프로젝트에서 따라야 할 작업 방식과 검증 기준을 문서화한다. 적용 범위의 지침을 읽고 현재 요청과 함께 작업 조건을 정리한다.

project_guidance + current_request
scope / conventions / validation

# 펫 확장 계획 이미지

제작: 2026-09-27, 내장 image_gen 도구.

- 참조 이미지: assets/cat-poses.png. 기존 검은 고양이의 얼굴·눈·색을 기준으로 제작했습니다.
- 저장 이미지: assets/pet-accessories-v1.png. 1280×1280 투명 배경의 2×2 시트입니다.
- 발표에서 사용하는 부분: 아래쪽 두 칸의 스카프 고양이와 작업복·모자 고양이.
- MCP는 이 시트의 일반 장난감을 사용하지 않습니다. 사용자 정정에 따라 공식 Figma·GitHub 로고를 별도 소품에 원본 비율로 배치했습니다.
- 원본 생성 이미지를 복사했으며 추가 이미지 편집 없이 CSS로 표시 영역을 정했습니다.

최종 생성 프롬프트:

```text
Use case: stylized-concept. Asset type: ONE transparent 2 by 2 sprite atlas for an AutoPets HTML presentation, same crisp pixel-art visual system. Reference image is identity and palette reference only: reuse exactly the friendly black cat, square mint-green eyes, triangular ears and right curled tail. Create a square canvas divided into FOUR equal invisible cells, wide transparent gutters, one isolated subject per cell, no subject crosses a cell. TOP LEFT: a small mint-green modular puzzle-cube toy with a short connector cable and plug, an adorable attachable toy representing an external MCP tool, no letters or logo. TOP RIGHT: a compact sage-green toy toolbox with handle, tiny cream tools peeking out, another MCP accessory, no letters. BOTTOM LEFT: the SAME black mint-eyed cat wearing a simple sage-green neck scarf, full body, friendly and dignified, paws visible, curled tail. BOTTOM RIGHT: the SAME cat with identical face, body proportions and eye color wearing a more developed cream utility coat with sage-green trim and a single tiny gold star pin, plus a small sage-green cap; visually an evolved, customized working partner, not a different animal. Both cats face front and have the SAME overall size and baseline in their cells. Cat outlines must match reference, use blocky pixel steps, no antialiasing, no painterly edges. Match the reference palette, restrained colors and cute expression. Canvas genuinely transparent alpha, keep opaque black fur and opaque cream clothing, do not make the cat's dark pixels transparent. Transparent margins about 12% of each cell. No background, no ground, no text, no numbers, no grid lines, no dividers, no UI. Exactly four isolated subjects.
```

Figma 로고는 [공식 브랜드 페이지](https://www.figma.com/using-the-figma-brand/)에서 제공한 로고 묶음의 Figma Icon (Full-color).svg를 assets/figma-logo.svg에 그대로 저장했습니다. 도형·색·비율을 변경하지 않고 SVG 바깥 여백만 CSS 표시 영역으로 조정했습니다.

## 2026-09-27 직무별 선택 화면 추가
9장 구성으로 수정했습니다. 3페이지의 원래 라이브러리 화면은 유지하고, 직무별 고양이·포니·부엉이·토끼를 새로 제작했습니다. 새 이미지 파일은 assets/role-pets-v1.png이며, 참조와 최종 프롬프트는 직무펫-이미지-프롬프트.md에 있습니다. PNG는 원본 그대로 복사하고 CSS로 2×2의 각 칸을 표시합니다.

문제 사례는 사용자가 전달한 메모를 익명 요약했습니다. 기존 인터뷰와 추가 메모를 합산하지 않았으며, 반대 사례와 시간·비용에 관한 팀의 문제 가설도 구분했습니다. 질문·추천은 약 3초 뒤 멈추고 다음 클릭을 기다립니다. 효과나 실제 연동 성공은 주장하지 않습니다.

## 고양이 행동 이미지
파일: assets/cat-poses.png
참조: 사용자가 승인한 실행 화면의 검은 고양이. 생성한 원본을 보존하며 CSS로 동일한 폭의 세 포즈를 선택해 표시합니다.
생성 프롬프트:
```text
Use case: ui-mockup supporting character asset. Generate one transparent-background horizontal sprite strip of EXACTLY THREE equally spaced poses of the SAME AutoPets black pixel cat from the reference, for a white HTML presentation. Reference is identity only, do not copy any UI.
Canvas requested 1536x512 (3:1 horizontal). True transparent background, NO white rectangle, NO checkerboard baked in. Three equal cells of 512x512, one pose centered safely within each cell, generous transparent margin 64px each side. Characters have exactly the same size, mint square eyes, upright triangle ears, tiny feet, and curled tail toward right.
LEFT cell: friendly idle black cat standing facing camera, empty paws, square mint eyes.
MIDDLE cell: same cat presenting an open cream-page sage-green planning notebook.
RIGHT cell: same cat typing at small silver laptop, mint eyes visible above laptop.
Crisp black pixel-art blocky edges, match screenshot cat identity, no dog or other animal. Full body in every pose. No shadow beyond tiny pixels beneath feet, no scenery, no labels, no letters, no text, no divider lines. No gradients, no extra props except the notebook and laptop. Three single cats only, no child cat or extra face. Keep equal transparent gutters so exact equal-third CSS cropping can select each pose cleanly.
```

## 발표용 사진 최적화
구르미 사진 4장만 1350×1800 WebP(품질 90)로 변환했습니다. 화면 비율과 내용은 그대로이며 원본 PNG는 로컬 assets/ 폴더에 보존했습니다. 발표 HTML과 편집 ZIP에는 WebP를 사용합니다. 픽셀 펫, 로고, 나머지 그림, styles.css, story.css, deck.js는 해시 비교로 변경 없음을 확인했습니다.

독립 HTML은 71.8 MiB에서 11.2 MiB로 약 84.3% 줄었습니다. 애니메이션과 클릭 동작 코드는 그대로입니다. 편집 ZIP은 발표에서 실제 사용하는 자산만 포함하고, 큰 원본 사진 PNG는 제외합니다.

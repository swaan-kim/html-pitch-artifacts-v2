# AutoPets 발표 — 20장

## 실행
AutoPets_5분발표.html을 브라우저에서 여세요. 이미지·로고·스타일·동작을 모두 포함해 인터넷 없이 실행됩니다. 발표자 메모와 하단 조작 안내는 없습니다. 기존 링크를 유지하기 위해 파일명은 그대로 두었습니다.

## 조작
- 화면 아무 곳이나 클릭 · → · Space: 다음 반응, 반응이 끝나면 다음 장
- ←: 이전 반응 또는 이전 장. 진행 중인 연출도 취소합니다.
- 1–9: 1–9장 / 0: 10장
- Home · End: 첫 장 · 마지막 장
- O: 전체 목차에서 20장 중 선택
- F: 전체 화면 / M: 모션 줄이기 / B: 화면 가리기
- ?: 숨겨진 조작 도움말 / Esc: 열린 창 닫기
- 마지막 장에서 E: 기존 피드백 편집 영역 열기

빈 곳·글자·펫·이미지·로고를 눌러도 같은 순서로 진행됩니다. 연출 중 다음 클릭은 무시하고, 연출이 끝나면 다음 클릭을 기다립니다. 이전 이동·숫자키·목차 이동은 연출을 취소합니다. 모션 줄이기는 현재 단계의 완성된 화면을 즉시 보여줍니다.

## 주요 전환
- 8장: 사진을 보여준 뒤 한 번 클릭하면 픽셀 조각이 모여 구르미로 전환합니다. 약 2.3초 후 멈춥니다.
- 9장: 한 번 클릭하면 MCP 브랜드 로고가 쌓이고 스킬명·설치 수·스타 수가 약 4.2초 동안 나타납니다. 다음 클릭에 추천 하나로 정리됩니다. 설치 수는 사용률이 아니며 스타는 품질 점수가 아닙니다.
- 11장: 한 번 클릭하면 약 3초 동안 질문·응답·추천이 이어지고 멈춥니다.
- 12장: 클릭마다 설정 → 계획 확인 → 실행으로 진행합니다.
- 13장: 선택 부담 → RouteLLM 공개 실험 → AutoPets의 계획·실행 설정 예시. 공개 실험 수치는 AutoPets의 결과가 아닙니다.
- 16장: 작업 반응 → MCP 소품 → 모델·추론 비교 → 하네스 → 외형 진화. 모델 비교는 몸 크기, 추론 비교는 동일한 몸 크기와 3칸 집중 게이지입니다.
- 18–20장: 같은 화면 요소가 위치를 옮기며 이어집니다. 마지막 결론에서 멈춥니다.

직접 이동은 주소 끝의 `#장/단계`를 이용합니다. 예: 구르미 사진 `#8/1`, 픽셀 구르미 `#8/2`, 정보 과잉 `#9/2`, 추천 `#9/3`, 라우팅 연구 `#13/2`, 모델과 집중 게이지 `#16/4`, 최종 결론 `#20/3`.

## 편집과 배포
원본은 index.html, styles.css, story.css, deck.js, assets/입니다. index.html을 열어 확인하고, Node.js가 있으면 `node build.mjs`로 독립 HTML을 다시 만들 수 있습니다. 별도 라이브러리는 필요하지 않습니다.

마지막 장에서 E를 누르면 기존 피드백 편집 영역이 열립니다. Esc로 종료하며 내용은 현재 브라우저에 저장됩니다. 이 수정은 다른 PC의 HTML에 반영되지 않습니다. 마지막 세 장의 본문을 바꾸려면 index.html의 closing-canvas를 수정합니다.

AutoPets-발표-전체.zip에는 독립 HTML, 편집 원본, 이미지·로고, 출처와 제작 기록, 지표 스냅샷을 함께 담았습니다. 발표자 대본은 포함하지 않습니다.


## 발표용 경량화
구르미 사진 4장을 발표용 WebP로 최적화해 단일 HTML을 약 11.2MB로 줄였습니다. 픽셀 펫·로고·클릭·애니메이션은 그대로입니다. 다른 컴퓨터에는 AutoPets_5분발표.html 하나만 옮기면 됩니다. 편집 ZIP에는 최적화된 사진이 포함되며 원본 PNG는 현재 컴퓨터의 assets/ 폴더에 보존되어 있습니다.

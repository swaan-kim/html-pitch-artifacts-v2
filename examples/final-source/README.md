# 최종 편집 원본

최종 20장 HTML을 만든 index.html, styles.css, story.css, deck.js, build.mjs의 원본 파일입니다. 원래 발표 파일은 변경하지 않았습니다.

이미지는 중복 보관을 줄이기 위해 저장소의 assets/templates/autopets/assets를 공유합니다. 실행·편집은 릴리스의 AutoPets-final-editable.zip을 내려받으세요. ZIP에는 assets/와 출처 문서, 독립 HTML이 함께 들어갑니다. node build.mjs로 원본 보관 HTML과 같은 파일이 만들어지는지 해시로 검사했습니다.
